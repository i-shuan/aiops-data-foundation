# 資料來源改成接口＋假資料分開；行事曆抓台灣行事曆（2026-10）

**狀態**：已完成（已合進 master）　　**日期**：2026-10-24　　**相關**：[慢性病清單與行事曆](2026-10-chronic-calendar.md)、[`engine/interfaces/README.md`](../../../aiops-engine/fake-data/interfaces.md)、[`engine/fake-data/README.md`](../../../aiops-engine/fake-data/README.md)
**模組**：② 清資料（外部資料來源）

## Plan：這一次要達到什麼

- **需求**：
  1. 行事曆要人每年手動填，還要處理補假、彈性放假，容易漏。
  2. 慢性病清單的「負責人」要別人提供，現在是空的，看不出清單長什麼樣。
  3. 假資料和長期使用的接口混在設定檔裡，換成真的時不知道要動哪裡。
- **目的**：程式只認資料的**格式**，來源可以換（檔案、URL、台灣行事曆）；假資料明確分開、標明是假的；假日改成直接抓台灣行事曆。
- **範圍**：做 `owners`、`calendar` 兩個介面與 `file`／`http`／`taiwan` 三種 provider。不做負責人的真來源。
